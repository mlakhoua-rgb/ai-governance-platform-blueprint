# Contributing

This repository is a curated reference architecture, but real-world governance patterns benefit from challenge and comparison.

## Welcome contributions

- **Issues** challenging a pattern, sharing how your organization solved the same problem, or pointing out failure modes not covered
- **Discussions** on tier definitions, evidence-pack contents, override telemetry, and compliance mappings
- **Pull requests** for typos, clarity, and additional anonymized patterns — noting that this repo intentionally contains **no production code, vendor specifics, or proprietary detail** (see [DISCLAIMER.md](DISCLAIMER.md)); PRs introducing them will be declined

## Ground rules

1. Keep everything **vendor-neutral and sanitized** — pattern level only
2. Argument over assertion: proposals should include the *why* and the failure mode addressed
3. No financial, legal, or regulatory advice — engineering governance only
